# alquimia-curso-ia-media

Portadas, animaciones y capturas del **Curso IA 2026-27** de AlquimIA.

Solo recursos públicos del curso: nunca datos del alumnado ni material privado.

- `portadas/`: portadas de las páginas de Notion (3000×1000).
- `animaciones/`: animaciones explicativas (SVG animado).
- `capturas/`: capturas de herramientas.
